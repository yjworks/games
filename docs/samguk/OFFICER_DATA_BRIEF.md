# 인물 데이터 작성 지침 (천하삼분)

`src/games/samguk/data/types.ts`의 `OfficerDef` 형식으로 인물을 작성한다.

## 원칙

1. **정사에 실존한 인물만**: 진수 『삼국지』(배송지 주 포함)·『후한서』·『진서』·『자치통감』에 나오는 사람.
   『삼국지연의』에만 나오는 가공인물(초선, 관색, 포삼랑, 축융, 올돌골, 대래동주, 하후은, 화웅의 연의 행적 등)은 넣지 않는다.
   연의 각색은 bio에 쓰지 않는다(예: 관우의 화웅 참수, 장비의 장판교 단기 삼만 격퇴 과장, 조운의 단기 오진).
2. **능력치는 이 게임의 독자 평가**: 다른 게임(코에이 삼국지 등)의 수치를 기억해 옮기지 말 것.
   기록된 행적을 근거로 아래 기준에 따라 직접 매긴다.
   - 통솔: 대군 지휘·용병 실적 / 무력: 개인 무용·선봉 실적 / 지력: 책략·판단 / 정치: 행정·내정·법제 / 매력: 인망·명성·사람을 끄는 힘
   - 95~100 시대 최고, 85~94 일류, 70~84 유능, 50~69 보통, 30~49 부족, 1~29 매우 부족
   - 기준점(이 값에 맞춰 상대 평가): 조조 [96,70,91,93,94], 유비 [76,74,72,77,98], 손권 [80,66,79,84,90],
     관우 [94,96,74,62,88], 장비 [86,97,30,24,42], 조운 [88,93,74,64,80], 제갈량 [93,38,99,96,93],
     사마의 [96,60,97,90,80], 여포 [86,100,28,14,36], 주유 [95,70,95,82,90], 순욱 [52,15,95,98,88],
     동탁 [84,85,58,22,16], 원소 [80,68,70,72,90], 장료 [94,92,78,58,78], 황개 [78,80,68,55,70], 유선 [12,10,22,28,60]
   - 문관은 무력을 낮게(10~40), 무관은 정치를 낮게 두는 식으로 개성을 살린다. 모든 값을 비슷하게 두지 말 것.
3. **연도**: 기록이 있으면 그대로. 없으면 행적으로 추정하고 `bornEst: true` / `diedEst: true`.
   출생이 전혀 알 수 없으면 첫 출사 연도 − 25 정도로 추정한다.
4. **svc(소속 이력)**: `[연도, 계통]` 오름차순. 첫 항목 연도 = 처음 벼슬·종군한 해(등장 연도).
   소속이 바뀐 해마다 항목을 추가(항복·귀순·주군 사망 후 이동 포함). 은거·낙향하면 `'none'`.
   계통 키는 `FactionKey` 목록만 쓴다. 군주가 바뀌어도 같은 계통이면 키를 유지한다(조조→조비 = 'cao', 손책→손권 = 'sun').
   위(魏)가 265년 진(晉)으로 넘어간 뒤까지 산 위 신하는 `[265,'jin']` 항목을 둔다.
   동탁 집권기(189~192) 조정에 있던 관료는 'dong', 그 이전 중앙 관료는 'han'.
   목록에 없는 작은 세력에 있던 시기는 가장 가까운 계통이나 'none'으로 둔다.
5. **home**: 고향(본적)에서 가장 가까운 게임 도시 id. 아래 도시 목록 참고.
6. **traits**: 0~3개, 확실한 근거가 있는 것만. 예: 감녕 수군·돌격, 육손 화계·신산, 화타 의술, 장합 매복(?)는 근거 약하면 넣지 않음.
7. **gi/amb**: 의리·야망 1~10. 여포 gi 1·amb 9, 관우 gi 10·amb 3, 맹달 gi 2 같은 식.
8. **father/bonds**: 같은 데이터 안에 있는 인물 id만. father는 친부(양부면 양부). bonds는 형제·부부·의형제·평생 주종.
   다른 파일 담당 인물도 id 규칙(병음)대로 적어도 된다 — 나중에 검증 스크립트가 없는 id를 걸러낸다.
9. **bio**: 정사 기반 한국어 1~2문장(40~110자). 관직·대표 행적·최후. 존댓말 아님, 평서문("~했다").
10. **id**: 이름 병음 소문자, 성조·공백 없음 (조조 caocao, 하후돈 xiahoudun, 제갈량 zhugeliang).
    동명이인은 뒤에 2, 3 (예: 장온 zhangwen / zhangwen2). 이름은 한글 표준 한자음(관우, 장비, 조운…).

## 파일 형식

```ts
import type { OfficerDef } from '../types';

export const OFFICERS_WEI: OfficerDef[] = [
  { id: 'caocao', name: '조조', hanja: '曹操', style: '맹덕', born: 155, died: 220, home: 'qiao',
    stats: [96, 70, 91, 93, 94], traits: ['명성', '둔전'], svc: [[174, 'han'], [189, 'cao']], gi: 6, amb: 10,
    father: 'caosong', bonds: ['xiahoudun', 'caoren'],
    bio: '패국 초현 사람. 헌제를 허도로 맞아들이고 관도에서 원소를 꺾어 북방을 통일했다. 위왕에 올랐고 220년 낙양에서 죽었다.' },
];
```

한 사람 한 줄(길면 두 줄)로 쓴다. 파일 끝에 다른 코드를 두지 않는다.
