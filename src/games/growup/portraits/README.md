# 초상 그림 넣는 곳

이 폴더에 그림을 넣고 다시 빌드하면, 게임의 초상(상태 창·대화창·졸업 화면)이 픽셀 아바타 대신 이 그림으로 바뀝니다.

## 파일 이름

| 파일 | 쓰이는 곳 |
|------|-----------|
| `elem-happy.png` | 초등학생, 기쁜 표정 |
| `middle.png` | 중학생, 모든 표정(표정별 그림이 없을 때) |
| `default.png` | 모든 학교급·표정(아무 그림도 없을 때) |

- 학교급: `elem`(초등) · `middle`(중등) · `high`(고등)
- 표정: `normal`(보통) · `happy`(기쁨) · `tired`(피곤) · `sad`(슬픔) · `sick`(아픔)
- 형식: `png` · `jpg` · `webp`

찾는 순서: `학교급-표정` → `학교급` → `학교급-normal` → `default` → 픽셀 아바타

## 그림 크기

- 세로로 긴 그림(가로:세로 = 3:4 정도)을 권합니다. 예: 240×320.
- 배경이 투명한 png면 상태 창 배경색 위에 자연스럽게 얹힙니다.
- 픽셀 아트면 작게(예: 48×64) 그려도 됩니다. 확대할 때 뭉개지지 않게 그립니다.

플레이어도 게임 안 「초상 바꾸기」에서 자기 그림을 올릴 수 있습니다(그 기기에만 저장). 플레이어가 올린 그림이 이 폴더 그림보다 먼저 쓰입니다.
